# Agent marks

These local assets identify the available runners; the picker never fetches logos at runtime.

- `claude.png`: [Claude product-site icon](https://assets.claude.com/95a868946ac8a31e5ff832e2899f294aa368b836.png?w=32&h=32), linked by [Claude Code](https://claude.com/product/claude-code).
- `codex.svg`: [OpenAI developer-site favicon](https://developers.openai.com/favicon.svg), the OpenAI mark used for Codex.
- `opencode.svg`: [OpenCode mark](https://github.com/anomalyco/models.dev/blob/dev/providers/opencode/logo.svg) from the upstream organization's models.dev repository.
- `antigravity.svg`: [Antigravity full-color icon](https://www.antigravity.google/assets/image/brand/antigravity-icon__full-color.svg), from its [press assets](https://www.antigravity.google/press).

The picker displays the monochrome OpenCode mark in white against its dark cards. The original files retain their source colors and proportions.
